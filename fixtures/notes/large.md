# Large document

A ~2000 line document that the smoke tests and the manual benchmarks render
when a linear-time guarantee is in question. The body is generated from a fixed
formula rather than typed by hand, so the file has no drift: section `n` always
carries the same shapes, and every heading under `Section` repeats the same text
so the slug generator has to deduplicate `notes`, `notes-1`, `notes-2`, and so on.

Generated content:

| property | value |
|----------|-------|
| sections | 86 |
| block kinds | headings, paragraphs, lists, code, tables, rules |
| assets | none — the file must render offline |
| math | none — see `math.md` for the formula fixtures |
